* # Automatic License Plate Recognition (ALPR) System

A complete Computer Vision pipeline designed to detect vehicle license plates from camera feeds and perform OCR character extraction.

## Key Features
* Bilateral filtering and Canny edge detection
* Contour approximation for rectangular plate segmentation
* Plate region extraction for OCR processing

## Tech Stack
* Python
* OpenCV (`cv2`)
* NumPy
