# Driver Drowsiness & Fatigue Detection System

An advanced safety system that uses facial landmark geometry to track Eye Aspect Ratio (EAR) and detect driver fatigue in real time.

## Key Features
* Geometric Facial Landmark & EAR calculation
* Real-time drowsiness alert threshold trigger
* Automated driver status reporting

## Tech Stack
* Python
* OpenCV (`cv2`)
* SciPy
